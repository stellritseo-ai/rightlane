## Developer Guide & Build Commands

### Prerequisites
- Node.js 20+ or 24+
- npm / yarn / pnpm

### Commands
```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle (SSR & client)
npm run build

# Preview production build locally
npx vite preview
```

### Key Source Files
- `src/lib/seo-schema.ts`: Schema.org structured data generator (LocalBusiness, Service, FAQ, Breadcrumb).
- `src/routes/__root.tsx`: Root HTML layout with canonical links, geo meta tags, and global JSON-LD.
- `public/robots.txt`: Production crawl rules and sitemap definition.
- `public/sitemap.xml`: Complete canonical XML sitemap.
- `src/routes/service-areas/`: Dedicated geographic hub routes for Tampa, Hillsborough County, Pinellas County, Clearwater, St. Petersburg, Brandon, and Tampa Bay.
- `src/components/site-header.tsx` & `src/components/site-footer.tsx`: Header navigation with Service Areas dropdown and comprehensive localized footer links.
